# Licenses and provenance

## Categories

- `ORIGINAL_GAME_SOURCE`: copyrighted Xenosaga I+II game data supplied by the user; never distributed here.
- `OUR_TRANSLATION`: rough-English translation and normalization produced in this project.
- `OUR_TOOLING`: parsers, rebuilders, QA scripts and runtime-fix code produced in this project workspace.
- `TECHNICAL_REFERENCE_VECTOR`: the public Vector Translations beta used for reverse-engineering comparison and technical evidence.
- `INTERNAL_METADATA`: Japanese lookup/index data intentionally preserved where classified as non-visible runtime metadata.

## Vector Translations reference

The Vector beta was used as a technical Rosetta Stone for early-game event structure, executable/UI differences, font/layout behavior and changed-asset discovery. The project does not claim a general license to Vector's English prose or graphics work.

The current graphics pass is explicitly marked as reference-derived engineering output. See `GRAPHICS_PROVENANCE.md`.

## No ROM distribution

No original or patched Nintendo DS ROM is included. Distribution is BPS patch-only and requires the user's own clean Japanese ROM.

## Repository license

This package intentionally does not declare a blanket license over game-derived content or third-party reference material. If the repository owner wants to license the original tooling separately, add a dedicated software license for those files only.
