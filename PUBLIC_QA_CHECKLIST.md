# Public QA checklist

Use this checklist when testing v0.1 RC1.

- [ ] Boot / title / New Game
- [ ] Opening dialogue readable
- [ ] `Yes / No` choice displays in English
- [ ] `Yes` tutorial branch continues
- [ ] `No` branch continues
- [ ] No isolated one-letter wrap lines
- [ ] Main menu opens
- [ ] Status menu readable
- [ ] Items / Ether / Equipment readable
- [ ] Options readable
- [ ] Incoming mail notification checked for Japanese residue
- [ ] Save / Load tested
- [ ] Battle target selection understood
- [ ] Normal attack successfully executed
- [ ] Battle menu / Ether / Item / Guard checked
- [ ] Later choice-heavy event tested
- [ ] Late-game event tested
- [ ] Screenshot/video attached for any defect

Public reference video: https://youtu.be/WXCLkwqY2JU
